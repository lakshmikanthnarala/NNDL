ABOUT THIS VERSION

Static front end, no server required.

This Pages build is a lightweight project showcase and practice interface. The original TensorFlow training scripts and model remain in the repository for experimentation; they are not part of this site.

  • Recognizes neither images nor live camera input.
  • Covers 24 static classes: A–I and K–Y.
  • Does not interpret motion, words, or sign-language grammar.
