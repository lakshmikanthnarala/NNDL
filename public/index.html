ABOUT THIS VERSION

Browser interface connected to a local Python model.

The local server delivers this page and runs the included TensorFlow classifier. Recognition is experimental: this model was trained on Sign Language MNIST, not ordinary camera photos.

  • Runs predictions locally; images stay on this computer.
  • Covers 24 static classes: A–I and K–Y.
  • Does not interpret motion, words, or sign-language grammar.
